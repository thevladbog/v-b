# v–b.tech

- `site/` — персональный лендинг-мокап (HTML, CSS, JS, RU/EN-контент + assets)
- `brand/` — бренд-борд (index.html), токены (tokens.css), логотипы v–b

Локально: `python3 -m http.server 4173 -d .` → сайт на /site/, борд на /brand/.

## Позиционирование
**End-to-end product engineer.** Влад отвечает за продукт целиком: от разбора
проблемы и UX до архитектуры, реализации, релиза и поддержки в эксплуатации.
Опыт с очередями, бейджами, складами, кассами и оборудованием служит
доказательством инженерной глубины, но не ограничивает предложение одной отраслью.

## Логотип — концепт «Сигнальный дефис»
Дефис из домена = фирменный глиф: янтарная полоса-индикатор (LED на железе /
штрих баркода / мост цифровое↔физическое). Wordmark: `v–b.tech` в IBM Plex Mono
SemiBold, дефис заменён на скруглённую янтарную полосу; `.tech` — Graphite 500.
На сайте дефис пульсирует (метафора online/offline).

- `logos/vb-mark-tile.svg` — монограмма (аватары, соцсети)
- `logos/vb-favicon.svg` — фавиконка (только дефис)
- Wordmark живёт в HTML/CSS (см. index.html, класс `.wm`); для печати —
  отрисовать текст в кривые.

## Ядро системы
- Цвет: графит (#0C0E10…#E8EAEC) + Signal Amber #F5A623, семантика:
  online #34C77B / error #E5533C / info #4C9AF0. Тёмная тема — основная.
- Шрифты: IBM Plex Sans (текст) + IBM Plex Mono (логотип, метки, цифры, код).
- Токены: `tokens.css`.
- Архитектура бренда: endorsed — продукты (QuokkaQ, Idento, Scanio,
  Mercadia.POS…) сохраняют имена, подписываются «a v–b.tech system».
