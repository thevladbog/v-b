# v-b.tech ACTIVE Contact Release Implementation Plan

> **For implementers:** Execute this plan in order with strict test-first changes and verification checkpoints.

**Goal:** Publish and enable the bilingual v-b.tech contact flow on the existing production contour with ACTIVE legal documents, immutable artifacts, reproducible deployment, controlled delivery evidence, and bounded rollback.

**Architecture:** The legal registry is the single source of truth for the paired ACTIVE identities. The web build embeds the selected form state, consent identity, public CAPTCHA key, and release SHA into immutable static bytes. The function archive and web image are published together, then a reviewed executor enables the existing Yandex runtime before replacing the existing edge web container. Disabled web bytes remain the first rollback target.

**Tech stack:** Astro 7, TypeScript, Vitest, Playwright, Node.js 24, Docker/Caddy, GitHub Actions, Yandex Cloud Functions, Cloud Postbox, SmartCaptcha, Managed PostgreSQL.
